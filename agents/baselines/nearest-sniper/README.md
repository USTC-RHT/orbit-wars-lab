# Nearest-Sniper Agent

## 策略概述

**最近星球狙击者**。对每个我方星球，找距离最近的非我方星球，若有足够舰船则立刻出征占领，否则等待积累。

## 执行流程

```
对每个我方星球：
  1. 找距离最近的非我方星球（enemy 或 neutral 皆可）
  2. 计算占领所需舰船数 = 目标当前舰船数 + 1
  3. 如果我方舰船数 ≥ 所需 → 计算 atan2 角度 → 发送
  4. 否则等待，下一回合继续积累
返回所有 moves
```

## 关键代码逻辑

```python
ships_needed = nearest.ships + 1
if mine.ships >= ships_needed:
    angle = math.atan2(nearest.y - mine.y, nearest.x - mine.x)
    moves.append([mine.id, angle, ships_needed])
```

## 特点

| 能力 | 是否具备 |
|------|---------|
| 星球旋转预测 | ✗ 直接用当前坐标 |
| 太阳路径规避 | ✗ 不检测太阳碰撞 |
| 防御逻辑 | ✗ 不考虑被攻击 |
| 多源协调进攻 | ✗ 每个星球独立决策 |
| 舰队数量优化 | ✓ 只发送刚好够的舰船（节省兵力） |

## 局限性

- 不预测旋转星球未来位置，发射角度可能偏差
- 不绕太阳飞行，若目标在太阳对面可能飞入太阳
- 不防御，敌人攻打己方星球时无响应

## 用途

- 功能完整的自定义基准 agent
- 展示如何解析观察值（obs）、计算角度、生成 moves
